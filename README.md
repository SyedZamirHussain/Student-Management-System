# Student Management System

A beginner-friendly, menu-driven **Student Management System** developed in C++.

## Features

* Add student records
* Display all students
* Search student by roll number
* Calculate average marks
* Find the student with the highest marks
* Exit the program

## Concepts Used

* C++ Functions
* Arrays
* Loops
* Conditional Statements
* Switch Statement
* User Input and Output
* Basic Searching and Calculations

## How It Works

The program provides a simple menu where the user can select an operation. Student information such as **name, roll number, and marks** is stored in arrays and can be displayed or searched during program execution.

## How to Run

1. Download or clone this repository.
2. Open the `.cpp` file in a C++ compiler or IDE.
3. Compile and run the program.
4. Use the menu to manage student records.
